## 🚀 DEPLOYMENT STEPS BY PLATFORM

### Railway (Recommended)
```bash
1. Go to https://railway.app/
2. Connect GitHub account
3. Select 'psn-college-erp' repository
4. Add environment variables:
   - MONGODB_URI=your_atlas_connection
   - JWT_SECRET=your_secret
   - NODE_ENV=production
5. Deploy automatically!
```

### DigitalOcean App Platform
```bash
1. Go to https://cloud.digitalocean.com/apps
2. Create App → GitHub → Select repository
3. Configure:
   - Build Command: npm install
   - Run Command: npm start
4. Add environment variables
5. Choose $5/month plan
6. Deploy
```

### Hetzner VPS (Advanced)
```bash
1. Create Hetzner account
2. Deploy Ubuntu 22.04 server
3. SSH to server and install:
   - Node.js, MongoDB, nginx
4. Clone your repository
5. Set up PM2 for process management
6. Configure nginx reverse proxy
7. Set up SSL with Let's Encrypt
```
